Questions.

Is the machine dedicated to me?

Yes. Every MiniRack plan is one physical machine, assigned only to you for the length of your rental. No virtualization, no neighbors. On Olares One you can invite your own teammates to join.

How do I connect?

You get a static IPv4 with SSH enabled, plus VNC / Apple Remote Desktop on Mac mini and remote desktop on Omarchy. Credentials arrive by email about 60 seconds after checkout.

Can I switch between Singapore and San Jose?

Yes. Reserve a machine in the other city and we'll help you move your data. Both racks offer all three machines at the same price.

Can you set up a coding agent for me?

Yes. We can install and configure a coding agent such as Claude Code or Codex on your machine so it's ready to work when you log in. This is an add-on, priced separately — mention it when you reserve.

What happens to my data when I cancel?

The disk is securely erased and the OS is reinstalled before the machine goes to the next customer.
